```powershell

The **Windows beta installer** workflow repeats TypeScript and Rust checks for pull requests, builds keyless unsigned MSI and NSIS bundles, and uploads short-lived version/commit artifacts. The protected **Publish public Windows beta** workflow repeats the full matrix from current `main` before creating a permanent manual prerelease. The separate protected **Publish signed automatic beta update** workflow verifies an existing release, signature and payload before replacing the fixed Beta channel manifest last.

It verified folder selection, recursive ingest, independent checksums, FFprobe metadata, MP4/WAV pairing, thumbnail generation, tag and project assignment, and persistence after restart. ## Test design rules

- Use synthetic or disposable fixtures; never personal footage.
- Keep destructive tests inside a uniquely created temporary fixture directory and verify its resolved boundary before cleanup.
- Assert outputs and failure state, not only that a call completed.
- Test interruption, replay, duplication, malformed inputs, and collision behavior for every persistent operation.
- Accessibility tests must exercise keyboard behavior and semantics. Manual assistive-technology checks remain necessary before release.
- FFmpeg-dependent tests may skip only with a visible reason. CI installs FFmpeg so those paths execute there.
- Record external application, OS, hardware, and version details for manual evidence.

The SD Grabber/global-deduplication suite uses synthetic card trees and Master Bin files. It covers recursive mixed-case MP4/WAV filtering, metadata exclusion, renamed/different-path SHA-256 matches, stale catalogue-only candidates, corrupted/missing local copies, same-size changed sources, active content reservations, source overlap, thumbnail-cache eviction and the Node adapter's concurrent destination race. UI coverage verifies the detected-card summary and copy-only action. These tests do not prove a particular physical card reader classification; installed Windows acceptance with disposable media remains required.

The 2026-11-04 regression correction additionally proves that inventory hashing is chunk-cancellable, a newer inventory cancels stale work before queueing, progress is exposed without blocking React, and copied bytes must match the approved source hash before promotion. These are synthetic correctness tests. They do not establish installed CPU/RAM utilization, physical-card read behavior, disconnect handling or crash-free shutdown; record those separately with the exact installer and disposable card before release.

The Clip Viewer component suite covers same-window open/back, portrait layout selection, previous/next navigation, validated playback-source lookup, unsupported-codec presentation, explicit proxy fallback, selection retention and device-local thumbnail-frame requests. Native proxy code fingerprints source identity and transform parameters, uses temporary no-overwrite cache output, validates with FFprobe, rechecks source stability and protects the returned proxy during eviction. Native frame tests use synthetic video and verify cache-only output and invalid time rejection. The suite does not yet prove proxy cancellation/progress, installed HEVC/WebView2 playback, fullscreen behavior, keyboard media shortcuts, high-DPI layout or real production footage.

Ingest UI coverage exercises all four one-off date choices from both persistent modes and proves a date change calls approved-plan reapproval rather than source inventory again. Native policy coverage checks Today, Yesterday, an explicit valid date and original-file dates against both saved modes. The reapproval command re-enumerates the selected paths, rejects changed snapshots, reuses approved SHA-256 values and rebuilds package-safe destinations and collision classifications; physical-card timing remains installed acceptance work.

Selection component coverage exercises the fixed toolbar contract, Ctrl+Z/Ctrl+Y selection history, preservation of native text-input undo, persistent device-local toolbar choices and reset behavior. Existing tests cover Ctrl/Shift/Ctrl+A and independent checkbox selection. Installed grid focus order, double-Escape timing, high zoom and screen-reader behavior remain manual acceptance items.

The saved-project index suite uses sanitized disposable gzip/XML fixtures shaped from observed Premiere 26 structure. It checks canonical definitions versus repeated references, four unique child-named sequences, root/nested bin placement, imported versus timeline-used versus previous path evidence, placement deduplication, unchanged source bytes, malformed XML, rejected document types and unsupported containers. UI coverage distinguishes saved-project counts, matched/unresolved evidence and sequence-associated recordings from future live provenance. These fixtures establish a narrow parser and safety boundary only; the personal source file was unavailable to this development environment, verified time ranges remain omitted, and no broad real-project or Companion coexistence acceptance is claimed.
