# Testing and verification

Never mark a check passed unless it was executed against the reported revision. Browser UI tests do not verify native Tauri behavior.

## Current repository commands

From `J:\projects\kairix-pimp`:

```powershell
npm install
npm test
npm run lint
npm run format
npm run build
npm audit --audit-level=high
```

`npm test` runs portable core, Node adapter, and jsdom React component/integration tests. `npm run build` type-checks project references and creates the production web bundle. CI repeats these checks on Ubuntu with Node 24 and FFmpeg. A separate `windows-latest` job runs native `cargo test` and `cargo check` with a cached stable Rust toolchain. The **Windows beta installer** workflow repeats TypeScript and Rust checks, builds unsigned MSI and NSIS bundles, and uploads them with a version/commit identity file. A reviewed numeric-prerelease `v*-*` tag publishes the manual Beta prerelease; only when protected updater signing configuration is present does it additionally build the signed updater payload and replace the fixed Beta channel manifest.

The October 2026 milestone acceptance pass used disposable generated H.264/AAC MP4 and WAV media in the native packaged application. It verified folder selection, recursive ingest, independent checksums, FFprobe metadata, MP4/WAV pairing, thumbnail generation, tag and project assignment, and persistence after restart. It did not use personal media or substitute browser-only behavior for native validation.

## Test design rules

- Use synthetic or disposable fixtures; never personal footage.
- Keep destructive tests inside a uniquely created temporary fixture directory and verify its resolved boundary before cleanup.
- Assert outputs and failure state, not only that a call completed.
- Test interruption, replay, duplication, malformed inputs, and collision behavior for every persistent operation.
- Accessibility tests must exercise keyboard behavior and semantics. Manual assistive-technology checks remain necessary before release.
- FFmpeg-dependent tests may skip only with a visible reason. CI installs FFmpeg so those paths execute there.
- Record external application, OS, hardware, and version details for manual evidence.
